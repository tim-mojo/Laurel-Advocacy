Connections (arrows)

Lines are drawn in SVG via JS. Add
data-id to nodes and declare
connections in the CONNECTIONS array. 
data-id="home" → data-id="about"
{ from: "home", to: "about", type: "pathway" }

Logo / Header

The logo slot is at #logo-slot.
Replace it with the brand <img>.
The project name is at #project-name. 
<img id="logo-slot"
  src="logo.svg" alt="Brand">

Project name

Replace PROJECT NAME with the
client or product name. Keep it short
and uppercase to match the layout.

</span>
